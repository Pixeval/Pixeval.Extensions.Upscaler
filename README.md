# Pixeval.Extensions.ImageTransformers

- [Real-ESRGAN](https://github.com/xinntao/Real-ESRGAN)

Release packages are built for `win-x64`, `linux-x64`, `osx-x64`, and `osx-arm64`.
The release workflow downloads the pinned Real-ESRGAN NCNN portable package for
the target platform, verifies its SHA-256 checksum, and bundles its executable
and models under `RealESRGAN/`.
